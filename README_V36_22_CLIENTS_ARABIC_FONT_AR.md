# BADR Atelier V36.22 — Clients + BIM Ecosystem + Arabic Typography

هذه النسخة مبنية مباشرة فوق V36.21 FULL.

## ما تم تحديثه
- إضافة قسم متحرك داخل الصفحة الرئيسية لخبرة العملاء المنشورة + منظومة مكاتب BIM والاستشارات متعددة التخصصات.
- فصل العميل/المرجع المنشور عن أسماء منظومة السوق حتى لا تتحول أسماء المكاتب العالمية إلى ادعاء بأنها جميعاً عملاء لـ BADR.
- إضافة 18 مكتباً/مرجعاً عالمياً وإقليمياً في الهندسة وBIM وPMC والتصميم.
- حركة Marquee مزدوجة في اتجاهين، Pause on Hover، وتأثيرات Hover متوافقة مع هوية BADR.
- دعم Responsive للموبايل والعربي/الإنجليزي.
- تحديث الخط العربي على مستوى الموقع إلى Tajawal بطابع عربي حديث ونظيف قريب بصرياً من الأسلوب المستخدم في موقع Advance KSA، مع بقاء الخط الإنجليزي كما هو.
- تطبيق الخط العربي أيضاً داخل BADR AI عندما تكون الواجهة عربية.

## ملاحظات
- الخط العربي يتم تحميله من Google Fonts عبر CSS؛ لم يتم تضمين أي ملفات خطوط داخل الحزمة.
- الإنجليزية لم تتغير Typography الخاصة بها.
