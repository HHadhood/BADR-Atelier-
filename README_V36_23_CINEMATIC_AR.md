## أهم التحديثات
- شاشة افتتاحية Cinematic لكل صفحة قبل إظهار المحتوى.
- صورة مختلفة ومعبرة لكل صفحة رئيسية ولكل صفحة مشروع/BIM.

- لا توجد روابط صور خارجية؛ جميع الصور من Assets الموقع لتبقى النسخة مناسبة لـ GitHub Pages.
- تمت المحافظة على BADR AI وWhatsApp وتعديلات V36.21.
