# BADR Atelier V36.30 — Visual Refinement

تحديث مبني مباشرة فوق V36.29.

- صفحة تواصل: بيانات القاهرة وجدة وأرقام التواصل والبريد أصبحت بيضاء داخل لوحات داكنة عالية التباين.
- صفحة الوظائف: تكبير وإبراز أرقام مسارات العمل 01–08، وأرقام القيم، وأرقام خطوات التقديم 01–04.
- صفحة الفريق: النصوص الداعمة في بطاقات الإحصاءات والملاحظات أصبحت سوداء وواضحة.
- صفحة الخدمات: قيم Entry Point / Output باللون الأبيض داخل لوحة داكنة من ثيم BADR.
- صفحة BIM + Digital: عناوين المبادئ الأربعة بالأسود، والأرقام 01–04 بحجم مضاعف تقريباً، مع بطاقات ذهبية فاتحة لقراءة أفضل.
- الصفحة الرئيسية + للمطورين: توسيط + و = هندسياً داخل دوائر واضحة.
- الصفحة الرئيسية: تحويل صورة الـHero إلى Project Reel متحرك يعرض مشروعات BADR واحداً تلو الآخر داخل نفس الإطار، مع اسم المشروع وعدّاد وتقدم زمني.
